# FilmCraft v0.6.0 RC1 한국어판 Windows 검증 체크리스트

테스트 환경 기록: Windows 버전/빌드, CPU/GPU, Rust (`rustc -vV`), VS Build Tools, Python, Inno Setup 버전 및 한국어 IME 상태.

## 자동 검사

- [ ] `TEST.cmd` (Python + Rust 테스트) 성공. deprecated IME 경고 여부 확인
- [ ] `BUILD.cmd` x64 GUI/CLI PE32+ 검사 성공
- [ ] `PACKAGE.cmd` 포터블 ZIP, `.sha256` 생성
- [ ] `INSTALL.cmd` 설치 EXE, `.sha256` 생성
- [ ] `VERIFY.cmd` 체크섬 및 ZIP 구성 검사 통과
- [ ] Windows Defender 검역/백신 탐지 여부 기록. 배포 파일에 코드 서명 적용 가능 여부 결정

- [ ] 한글·영어 혼합 영역 선택/교체/복사/붙여넣기/Undo/Redo
