# FilmCraft v0.5.5 한국어 실기기 QA 체크리스트

버전: 비공식 Korean Patch v0.5.5. 실제 Windows에서 담당자가 확인해야 할 항목입니다. 소스 배포 ZIP에 컴파일된 Setup.exe는 들어 있지 않습니다.

## 선행조건

- Windows 10/11 x64, 한국어 입력기(Microsoft IME), 한글 폰트(맑은 고딕 등).
- `TEST.cmd`와 `BUILD.cmd` 성공, `INSTALL.cmd`로 생성한 Setup.exe가 있다면 설치 후 실행.
- 가능하면 시작 전에 기존 프로젝트를 별도 폴더에 백업합니다.

## 수동 입력/그래픽 테스트

- [ ] Program Monitor에서 텍스트 도구(T) 클릭 → `안녕하세요 한글 편집 테스트` 입력.
- [ ] 조합 중 `ㅎ`→`하`→`한` 상태가 표시되고 확정 시 **한 번만** 삽입되는지 확인.
- [ ] IME 후보 선택 중 Enter/Backspace/Esc/방향키로 레이어가 잘못 수정되지 않는지 확인.
- [ ] NFD 형태 `한`과 `👩‍💻`를 붙여넣고 Backspace 1회당 글자 하나가 지워지는지 확인.
- [ ] 한글 선택 영역을 다른 한글로 교체하고 Ctrl+Z/Ctrl+Y 재실행 확인.
- [ ] Source Text 패널에서 한글 입력, 선택, 복사/붙여넣기 확인.
- [ ] UI 언어를 영어로 변경한 뒤에도 한글 영상 텍스트가 보이는지 확인.
- [ ] 프로젝트 저장 → 프로그램 종료 → 재실행 → 제목 한글 및 글꼴 확인.

## 자막·영상 내보내기 테스트

- [ ] `안녕하세요!\n자막 테스트입니다.` 2줄 SRT 가져오기/저장/재가져오기.
- [ ] WebVTT에서도 동일한 한글·줄바꿈 보존 확인.
- [ ] UTF-8 BOM 및 Windows CRLF 자막 파일 가져오기.
- [ ] 1920×1080 H.264로 5초 분량 테스트 내보내기 후 글자가 깨지지 않는지 육안 확인.
- [ ] Export 프레임과 Program Monitor 자막의 줄바꿈·글꼴을 비교.

## 설치/배포 테스트

- [ ] `INSTALL.cmd`로 Setup.exe 생성.
- [ ] 관리자 권한 없이 사용자별 설치가 되는지 확인.
- [ ] 바로가기 및 프로그램 실행 확인.
- [ ] 업데이트/제거 후 이전 프로젝트·사용자 설정이 삭제되지 않는지 확인.
- [ ] 재설치 후 한글 입력과 영상 내보내기 재검증.

실패가 있으면 Windows 버전, MS IME 설정, 글꼴, `TEST.cmd` 출력, 재현 절차를 기록합니다.
