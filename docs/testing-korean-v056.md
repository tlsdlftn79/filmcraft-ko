# FilmCraft v0.5.6 한국어 실기기 검증 안내

**중요:** 작성된 테스트는 실제 Windows에서 실행해야 합니다. 이 환경에서는 Rust/MSVC/Windows IME 및 Inno Setup을 실행할 수 없어 실행 완료로 표기하지 않습니다.

## 1. 자동 검증

`TEST.cmd` → `BUILD.cmd` → `INSTALL.cmd` 순서로 실행하고 Exit Code 0과 생성된 결과 파일을 확인하세요.

- `target\release\filmcraft.exe`
- `dist\FilmCraft_v0.5.6_Korean_Windows_x64_Setup.exe`

`TEST.cmd`에서는 한국어 IME Commit/Preedit 중복 검사, 문자 경계 이동, 한국어 SRT·VTT 왕복 및 한국어 줄바꿈 Rust 단위 테스트를 실행합니다. Rust 컴파일이 실패한다면 전체 로그를 보관하세요.

## 2. IME 수동 테스트

- [ ] 프로그램 미리보기 텍스트 도구(T)를 켜고 한국어 `한글` 조합 및 확정 시 1회만 삽입되는지 확인
- [ ] 확정 이벤트 뒤 다른 문자를 연속 입력했을 때 누락이 없는지 확인
- [ ] 한국어 → 영어 전환 직후 영문 입력이 무시되지 않는지 확인
- [ ] IME 후보 선택 중 Enter/Backspace가 자막에 중복 반영되지 않는지 확인
- [ ] `한`(분해 자모), `👩‍💻` 입력 뒤 Backspace와 Ctrl+좌우로 중간 분리되지 않는지 확인
- [ ] Source Text 입력/붙여넣기/복사, 재시작 후 저장된 한글이 유지되는지 확인

## 3. 자막 출력 및 설치

- [ ] 띄어쓰기 없는 긴 문장 `한국어자막줄바꿈테스트`를 반복 입력해 미리보기에서 프레임 밖으로 넘어가지 않는지 확인
- [ ] 1920×1080와 640×360에서 SRT/VTT 자막을 가져와 내보낸 뒤 줄바꿈 비교
- [ ] 한국어 글꼴, 이모지, 조합 자모가 영상 내보내기에서 올바르게 나오는지 육안 확인
- [ ] 관리자 권한 없는 사용자 설치·업데이트·제거 후 프로젝트와 설정 유지 확인
- [ ] 설정 → 한국어/영어 언어 전환 및 재시작 후 상태 복원 확인

## 4. 실패 기록

`rustc --version`, `cargo --version`, Windows 버전, 입력기 종류, 오류 로그, 스크린샷(가능한 경우)을 함께 보관하세요. 테스트를 통과하기 전에는 한국어 안정판으로 표기하지 마세요.
