# FilmCraft RC6 — 후원 버튼 Windows 실기기 체크리스트

- [ ] Windows 10/11 x64에서 `TEST.cmd`, `BUILD.cmd`, `INSTALL.cmd` 실행
- [ ] 넓은 창에서 상단 `한국어판 후원` 버튼 표시
- [ ] 버튼 클릭 시 기본 브라우저에서 정확히 `https://ctee.kr/place/caw` 열림
- [ ] 창 너비를 좁혀 버튼이 숨겨져도 **도움말 → 한국어 패치 후원…** 동작
- [ ] `도움말 → FilmCraft 정보 → 한국어판 후원` 동작
- [ ] 영어·일본어·스페인어 등 다른 UI 언어에서 레이블이 정상 표시
- [ ] 네트워크가 연결되지 않거나 브라우저가 없더라도 FilmCraft가 비정상 종료되지 않음
- [ ] 후원하지 않아도 문자 도구, GPU/CPU 내보내기, YouTube Shorts 및 프로젝트 저장 정상 동작
- [ ] 기존 RC5 설치판에서 RC6 업데이트 후 설정·프로젝트 데이터 유지

**메모:** 정적 검사는 UI를 클릭하거나 외부 사이트의 결제 기능을 검증하지 못합니다.
