# RC5 실기기 검증 체크리스트 (Windows 10/11 x64)

## 준비

Windows MSVC Rust 1.95+와 C++ Build Tools, Python3 및 Inno Setup 6.3+을 설치합니다.

```bat
TEST.cmd
BUILD.cmd
PACKAGE.cmd
INSTALL.cmd
VERIFY.cmd
```

위 명령이 성공해야 다음 단계로 진행합니다. `TEST.cmd`가 통과해도 GUI 조합 테스트가 자동으로 검증되는 것은 아닙니다.

## 입력 테스트

- [ ] 문자 도구로 `한한`, `안녕하세요 ABC 123`, `😀 한글`을 입력하고 결과를 확인
- [ ] 연속 `ㅎ → 하 → 한` 조합이 중복 저장되지 않는지 확인
- [ ] 한글 후보를 Enter/Escape로 확정/취소하고 글자가 사라지거나 두 번 들어가지 않는지 확인
- [ ] `Backspace`로 한글 및 이모지 삭제 후 화면과 프로젝트 저장값이 일치하는지 확인
- [ ] Source Text 패널로 초점을 이동한 뒤 문자 도구를 다시 클릭해 조합 확인
- [ ] 한글 제목을 저장하고 프로젝트를 닫았다가 다시 열기

## YouTube Shorts 및 GPU

- [ ] 빠른 내보내기에 `유튜브 쇼츠 1080×1920 (9:16)` 선택
- [ ] 파일명 `나의 영상.mp4`을 한 글자씩 수정하는 동안 이름이 사라지지 않는지 확인
- [ ] 다른 프리셋으로 이동할 때 이름은 유지되고 확장자만 바뀌는지 확인
- [ ] 쓰기 불가 경로로 내보내기 실패 시 팝업이 유지되어 다시 시도 가능한지 확인
- [ ] CPU 방식 1080×1920 H.264/AAC MP4 내보내기
- [ ] NVIDIA NVENC GPU 자동 모드(지원 PC) 내보내기 및 CPU 폴백 확인
- [ ] 내보낸 영상을 재생하여 한글 자막·화면 비율·음성 동기화 확인

## 설치/제거

- [ ] `INSTALL.cmd` 생성 Setup.exe 설치 확인
- [ ] 시작 메뉴/바탕화면 바로가기 실행
- [ ] 설치판 업데이트 및 제거 후 사용자 프로젝트 데이터 보존 확인
- [ ] 생성물 `VERIFY.cmd` 및 SHA-256 검증

실제 실행 시 로그와 첫 실패 명령의 전체 오류 내용을 보존해 주세요.
