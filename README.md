# FilmCraft v0.6.0 RC3 — 한국어판

**FilmCraft**는 Rust 기반의 오픈소스 비선형 영상 편집기입니다. 멀티트랙 타임라인, 영상·오디오 편집, 색보정, 이펙트, 그래픽 텍스트, 자막, 영상 내보내기 기능을 하나의 작업 환경에서 제공합니다.

이 저장소의 **v0.6.0 RC3**은 [원본 FilmCraft](https://github.com/storytold/filmcraft)를 기반으로 한국어 인터페이스와 한글 텍스트·자막 호환성을 보완하는 **비공식 한국어 패치 버전**입니다. 원본 프로젝트의 버전 및 공식 릴리스와는 별도로 관리됩니다.

> **현재 상태: RC(Release Candidate) / 테스트 단계**
>
> RC3 소스에 수정 코드와 회귀 테스트가 포함되어 있지만, Windows 실기기에서의 한글 문자 도구 입력, 설치·업데이트·제거, GPU 미리보기 및 최종 MP4 내보내기까지 모두 검증된 안정판은 아닙니다. 특히 **문자 도구의 한글 입력 불가 문제는 후속 최우선 수정 대상**입니다.

## v0.6.0 RC3 한국어 패치 변경 사항

- **한국어 UI:** 한국어 번역 카탈로그 3,756개 항목을 반영하고 언어 선택·설정 유지 경로를 제공합니다.
- **한글 IME 처리:** 조합 완료 및 취소 과정에서 Enter·Backspace·Escape가 중복 적용되지 않도록 입력 이벤트 처리 로직을 보완했습니다. 실제 Windows 문자 도구에서의 한글 입력은 추가 수정·검증이 필요합니다.
- **자막 글꼴:** 자막에 지정한 `CaptionStyle.font`가 글자 폭 계산, 줄바꿈, 미리보기·출력 렌더링에 사용되도록 수정했습니다.
- **구형 SRT 파일:** CP949로 저장된 한국어 SRT 불러오기 경로를 추가했습니다. UTF-8 및 BOM 기반 문자 인코딩 처리도 유지합니다.
- **긴 한글 자막:** 외곽선과 배경 여백을 고려하여 줄바꿈 폭을 계산하고, 자막 임시 이미지 버퍼의 크기를 영상 프레임 내로 제한했습니다.
- **회귀 테스트:** 한글·영문 혼합 그래픽, 자막 인코딩 왕복, 글꼴 처리, 출력 범위 등에 대한 테스트 코드를 추가했습니다.
- **배포 준비:** 비공식 한국어판 설치·포터블 패키징 및 무결성 검사, Windows 자동 검증 워크플로 정의를 포함합니다. 실제 결과물의 성공 여부는 별도 검증이 필요합니다.

## 알려진 문제 및 검증 필요 항목

- [ ] **문자 도구(T)에서 한글 IME 입력 불가 문제 해결**
- [ ] 조합·확정·취소, 한/영 전환, 커서 이동, 선택·붙여넣기 동작을 Windows에서 확인
- [ ] `egui::ImeEvent::Disabled` 관련 deprecated 코드 제거 및 입력 이벤트 호환성 점검
- [ ] 한국어·영문 혼합 텍스트의 줄바꿈, 선택 영역, Undo/Redo 확인
- [ ] 한글 자막 글꼴·외곽선·배경이 미리보기와 실제 MP4 결과에서 일치하는지 검증
- [ ] CP949, UTF-8, UTF-8 BOM, UTF-16 BOM 자막 파일의 입출력 확인
- [ ] 긴 자막과 고해상도 영상에서 메모리 사용량·화면 잘림 검증
- [ ] Windows 설치, 업데이트, 제거, 포터블 실행 및 프로젝트 보존 확인
- [ ] 다양한 실제 촬영 파일에서 영상·오디오 싱크, 성능, 충돌·복구 확인

## 향후 개발 로드맵

아래 일정은 **구현 목표**이며 완료되었다는 뜻이 아닙니다. 버전 이름과 기능 범위는 테스트 결과에 따라 조정될 수 있습니다.

### v0.6.0 RC4 — 한글 문자 도구 안정화 (최우선)

- [ ] Windows 한글 IME Preedit/Commit 경로 전체 재점검 및 한글 입력 불가 문제 수정
- [ ] 조합 중 커서 위치, 삭제, 글자 선택, 입력 취소, 다중 줄 편집 안정화
- [ ] 한/영 혼합 문장 및 특수기호·이모지 입력 보완
- [ ] 글꼴 폴백 및 한글 자간·행간·텍스트 상자 처리 개선
- [ ] IME 이벤트 변경에 따른 경고·호환성 문제 정리
- [ ] 실제 Windows 환경 회귀 테스트 확대

### v0.6.0 RC5 — YouTube Shorts 빠른 내보내기

- [ ] **빠른 내보내기에서 'YouTube Shorts' 전용 프리셋 제공**
- [ ] 세로형 9:16, 기본 1080 × 1920 출력 프리셋
- [ ] 30/60fps 선택, H.264 영상 + AAC 오디오 설정
- [ ] 가로 영상의 세로형 리프레이밍·크롭·여백 처리 옵션
- [ ] 자막 및 화면 요소의 세로 화면 안전 영역 가이드
- [ ] 일반 YouTube 영상용 16:9 프리셋과 구분
- [ ] 출력 파일명·저장 위치·품질 선택 및 실제 업로드 호환성 테스트

### v0.6.0 RC6 — GPU 하드웨어 인코딩 확장

- [ ] **내보내기 화면에 GPU 인코딩 장치·방식 선택 UI 추가**
- [ ] NVIDIA NVENC, AMD AMF, Intel Quick Sync Video(QSV) 지원 범위 조사 및 구현
- [ ] 기존 원본 프로젝트의 일부 하드웨어 인코딩 경로를 한국어판에서 연결·검증
- [ ] 지원 GPU·드라이버·코덱 자동 감지
- [ ] H.264 / HEVC 하드웨어 인코딩의 지원 조합 및 품질 설정 확장
- [ ] 하드웨어 사용 불가 시 소프트웨어 인코딩으로 안전하게 전환
- [ ] CPU 대비 인코딩 속도, GPU 사용량, 영상 품질 및 오류 복구 테스트

> **GPU 지원 주의:** 원본 FilmCraft에는 플랫폼과 장치에 따른 일부 하드웨어 인코딩 경로가 이미 존재합니다. 위 작업은 모든 제조사 GPU 지원이 RC3에 완료되었다는 뜻이 아니라, 해당 경로의 한국어판 UI 연동과 확대·검증을 목표로 합니다.
